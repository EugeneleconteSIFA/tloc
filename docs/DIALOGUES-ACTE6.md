# Les répliques de l'acte VI — la rive oubliée (version 1, 7 octobre) — **à valider**

Le texte de l'acte VI, étape par étape (`DECOUPAGE-ACTE6.md`), selon la règle des conversations de
`SCENARIO.md` (§ 7). Rien n'est codé. Étapes (`state.acte6`) : `felure`, `descente`, `riviere`, `escalier`,
`rive`, `forge`, `metal`, `tombe`, `cloche`.

**Les types** : **A** ambiance (jamais de gras) ; **S** souvenir (jamais de gras, jamais de consigne) ;
**I** indice (le gras dit ce qui sert).
