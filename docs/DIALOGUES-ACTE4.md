# Les répliques de l'acte IV — les Pouilles (version 1, 6 octobre) — **à valider**

Le texte de l'acte IV, habitant par habitant, étape par étape (`DECOUPAGE-ACTE4.md`), selon la règle
des conversations de `SCENARIO.md` (§ 7). Rien n'est codé.

## Comment lire ce fichier

Les étapes (`state.acte4`) : `arrivee`, `quinze`, `grandpere`, `trente`, `rythme`, `soixante`, `corde`,
`tambourin`, `chateau`, `colosse`, `heures`. Un habitant dit la réplique de l'étape la plus récente
qui lui en donne une.

**Les types** : **A** ambiance (jamais de gras) ; **S** souvenir (jamais de gras, jamais de consigne) ;
**I** indice (le gras dit ce qui sert ; « besoin » : ce qu'il demande, en poche ou à portée).

Camille parle peu.
